SHPILKA / SPRÁVA PORTFÓLIA

Administrácia realizácií

Pridávajte projekty, opisy a fotografie priamo na shpilka.sk. Verejný dizajn stránky zostáva bez zmeny.

1. Pripojenie k vášmu GitHub účtu

Web je na GitHub Pages. Na zápis fotografií potrebuje oprávnenie k repozitáru EnderSsh/shpilka. Vytvorte si fine-grained token na GitHube: Repository access → Only select repositories → shpilka, Permissions → Contents → Read and write.

Token neukladáme do súborov webu ani do úložiska prehliadača. Existuje iba počas otvorenej relácie. Nikomu ho neposielajte.

2. Existujúce realizácie

Balík ZIP obsahuje súbor realizacie/projects.js a fotografie v realizacie/foto/. Import pripraví zmeny; na web sa zapíšu až po kliknutí na „Publikovať na webe“.
